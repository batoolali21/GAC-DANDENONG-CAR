 🚗 GAC Dandenong – Car Rental Website

A modern and responsive **Car Rental Website** developed as a practice web development project. The website provides users with a simple and attractive interface to explore available cars and make a rental booking.

 📌 Project Overview

**GAC Dandenong** is a front-end car rental website designed to provide a smooth and user-friendly car booking experience.

The project focuses on practicing:

* HTML5
* CSS3
* Bootstrap 5
* Responsive Web Design
* Navigation and multi-page layouts
* Forms and user input
* Hover effects and transitions
* Modern UI design

 ✨ Features

* 🏠 **Home Page** – Introduction and featured content
* 🚘 **Cars Page** – Browse available car models
* 📅 **Booking Page** – Reserve a car using a booking form
* 📋 **Booking Details** – Enter name, email, phone, car model, pickup date and return date
* ✅ **Confirmation Page** – Displays the booking confirmation after submitting the form
* 📱 **Responsive Design** – Works across different screen sizes
* 🎨 **Modern Dark UI** – Gradient backgrounds, glass-style cards and modern typography
* ✨ **Hover Effects** – Interactive cards and navigation elements
* 🔽 **Dropdown Navigation** – Additional navigation options through the More menu

 🚘 Available Car Models

The booking form currently includes:

* Toyota Fortuner
* Mercedes Benz
* Hyundai Sonata

 📝 Booking Form

The booking page allows users to enter:

* Full Name
* Email
* Phone Number
* Car Model
* Pickup Date
* Return Date
* Special Requests

After submitting the form, the user is directed to the confirmation page.

 🎨 Design

The website uses a modern visual style with:

* Dark gradient backgrounds
* Rounded cards
* Glassmorphism effects
* Responsive Bootstrap components
* Smooth hover animations
* Modern typography
* Responsive navigation

The custom CSS applies transitions and lift-up hover effects to cards to make the interface more interactive.

 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Navigate through the website using the navigation menu.
5. Go to the **Booking** page to test the booking form.

No backend or database setup is required for this practice project.
